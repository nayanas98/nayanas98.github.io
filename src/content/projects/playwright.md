A production-ready End-to-End testing framework built with Playwright.

- Implementation of **Page Object Model (POM)** for high maintainability.
- Parallel test execution and cross-browser validation (Chromium, Firefox, Webkit).
- Automatic HTML reporting and screenshot capture on failure.
- Integrated with **GitHub Actions** for automated CI/CD execution.
